# 縮尺よみ（shukushaku-yomi）

地図の4cmは何km？ 地形図の縮尺から実際の距離・面積・地図の長さを計算し、等高線を数えて高さを読む1日5問の学習ゲーム。正解したら「どう計算した？」も選びます。

遊ぶ：https://satou-aaaaa.github.io/shukushaku-yomi/

- 決まりは、国土地理院の資料で確かめたことだけ（2026-11-17 に読んだ）。
  - [距離と縮尺](https://www.gsi.go.jp/KIDS/KIDS04.html)（2万5千分の1地形図では4cmが1km）
  - [等高線](https://www.gsi.go.jp/KIDS/KIDS07.html)
  - [2万5千分1地形図図式（表示基準）](https://www.gsi.go.jp/common/000218186.pdf)（主曲線10mごと・計曲線50mごと・補助曲線は主曲線の間を5m又は2.5mごと）
- 等高線の問題は、資料で確かめられた2万5千分の1の地形図だけを出します。
- 地図の長さ・高さの数字は練習用の作り話です。公式の情報の代わりではありません。地形図の決まりは国土地理院の資料で確かめてください。
